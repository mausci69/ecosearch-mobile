# EcoSearch Mobile: local-first evidence retrieval on prepared corpora

Published on LinkedIn: 2026-07-06

Small but important EcoSearch milestone: the mobile app now runs as a standalone iOS preview.

The idea behind EcoSearch is simple: not another chatbot, but a local evidence-search tool for documents.

Instead of generating first and explaining later, EcoSearch retrieves supporting text first, keeps the evidence visible, and allows the semantic/lexical retrieval balance to be tuned.

The current preview can query prepared corpora directly in the app. Corpus preparation still uses an OpenAI key, but once the corpus is prepared, the core retrieval workflow can run locally. I validated that retrieval flow in airplane mode.

This mobile preview is part of the broader EcoSearch v1.1 work, where I’m also writing up the retrieval model, the semantic/lexical balance experiments, and the evaluation results in a white paper.

For me, this is the interesting layer: retrieval quality, source visibility, and grounded evidence access before generation.

Next step: polishing the mobile demo flow and finalising the white paper across multiple corpora.

I’m especially interested in conversations around retrieval, search relevance, RAG evaluation, evidence-grounded systems, and local-first AI workflows.
